# Tresor CalcUtils

A simple Python mathematical utility package created as part of a Software Engineering and Python Development lab.

- TestPyPI project: https://test.pypi.org/project/tresor-calcutils-2026/0.1.0/

## Features

- Add two numbers
- Multiply two numbers
- Calculate the average of a list of numbers

## Installation

```bash
pip install --index-url https://test.pypi.org/simple/ --extra-index-url https://pypi.org/simple/ tresor-calcutils-2026
```

## Usage

```python
from calcutils import add, multiply, average

print(add(10, 25))
print(multiply(5, 4))
print(average([10, 20, 30, 40]))
```

Expected output:

```text
Addition: 35
Multiplication: 20
Average: 25.0
```
